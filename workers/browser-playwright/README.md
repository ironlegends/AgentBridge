# Bundled browser worker

Agent Bridge uses this isolated browser worker for qualified Windows browser automation. The portable release includes the pinned Node.js, Playwright and Chromium dependencies; users do not need to install them separately. This document is for developers and release maintainers. For ordinary setup, see the [Quick Start Guide](../../docs/QUICKSTART.md).

The Rust provider launches one Node worker directly, hidden and inside a Windows
Job, per isolated browser session. The worker launches Playwright Chromium through
its private pipes. There is no CDP listener, external CDP attach, personal Chrome
profile, auxiliary web service or installation step at application startup.

## Frozen dependencies

| Component | Release | Provenance and verification |
| --- | --- | --- |
| Node.js | 24.14.0 win-x64 | Official nodejs.org ZIP and node.exe SHA-256 from SHASUMS256.txt |
| playwright-core | 1.65.1 | Exact npm archive SHA-512 integrity in package-lock.json |
| Chromium for Testing | 159.0.8154.6, Playwright revision 1255 | Distribution URL from this Playwright package's browsers.json/installer, exact archive SHA-256 |

The fixed hashes are constants in `scripts/rust/package-browser-worker.py`.
The build only accepts offline archives. It rejects traversal, case aliases,
links, unexpected versions, oversized archives and changed release digests.
The output must be a fresh directory; it never replaces an installed runtime.

## Reproducible Windows build

Obtain the three official archives at build time:

* https://nodejs.org/dist/v24.14.0/node-v24.14.0-win-x64.zip
* https://registry.npmjs.org/playwright-core/-/playwright-core-1.65.1.tgz
* https://cdn.playwright.dev/builds/cft/159.0.8154.6/win64/chrome-win64.zip

Keep the Node release SHASUMS256.txt with build evidence. `npm ci --omit=dev
--ignore-scripts --no-audit --no-fund` installs only the locked Playwright package
for development. Set `PLAYWRIGHT_BROWSERS_PATH` to a private build directory and
run `node node_modules/playwright-core/cli.js install --no-shell chromium` when
collecting the dedicated browser at build time. This command is never in the
installed app's launch path.

Capture the legal credits from that dedicated browser using
`node capture-credits.mjs <absolute-chrome.exe> <new-credits.html> <private-temp>`.
Then run the packager from the repository root:

```text
python scripts/rust/package-browser-worker.py --node-archive <node.zip> --playwright-archive <playwright.tgz> --chromium-archive <chrome.zip> --chromium-credits <credits.html> --output <fresh-bundle-directory>
```

The printed `manifest_sha256` is sealed in the native capability configuration.
All file hashes are verified and their physical resources held read-only for
the provider lifetime. The manifest covers the dedicated Chromium runtime,
Node, worker, Playwright package and legal notices. Updating them requires a new
qualified bundle and capability generation, not an ambient Chrome update.

## Private protocol and lifecycle

Frames contain a four-byte little-endian length and UTF-8 JSON. Requests are at
most 1 MiB, replies at most 48 MiB. Correlation IDs strictly increase; the version
is exactly 2. Partial writes/reads are supported. Truncated, oversized, replayed,
uncorrelated or malformed frames revoke the session and drain its Job. Stderr
contains bounded structured diagnostic metadata without page URLs or secrets.

A normal Playwright timeout returned through valid IPC preserves a usable
session only with an explicit positive usability marker and reports the completed
prefix. Method-specific replies are checked against their session, observation
and reservation before becoming MCP results. A transport deadline or uncertain
worker state closes admission and terminates the owned process tree; an owner
is retained until both the root and its Job are verified empty.

Each observation is an opaque, 30-second, one-use capability tied to the
worker, session, page and captured state. A batch has 1–20 fully prevalidated
actions and at most one mutation; real waits may accompany it. Attempts consume
the observation before file staging. One opaque 30-second reservation per
session freezes all actions/options, the observed page and its generation. The
private `reserve_act`/`act` continuation is one-use; `cancel_act`, expiry,
navigation and closure destroy it. Waits cannot retarget a later mutation to an
active popup, and page generation is checked immediately before a mutation.
Navigation, dialog and page events invalidate old observations. Inactive sessions close after 30 minutes. Persistent profiles
are exclusive, explicitly selected and separate from every personal profile.

Uploads enter only through the Rust common-filesystem callback into the private
session staging directory `uploads/<reservation_id>` generated by Rust. Invalid
observations invoke no file callback. Abandoned attempts are removed; files
possibly backing a live file input remain private until its owned Job drains. Downloads are streamed with a 64 MiB limit and sent
to the artifact publication callback. Snapshot PNGs are bounded to 32 MiB and
returned as actual MCP image blocks, with structured metadata alongside them.

A separately bounded 16 KiB private execution receipt survives snapshot, PNG,
serialization and response-budget failures. It carries the completed prefix,
session/page identities and any private download descriptor. Rust publishes or
cleans that download and retains the committed artifact identity even when a
later output step fails. Failed owners remain revoked and retryable without
blocking unrelated healthy sessions; session listing reports pending cleanup.

## Qualification

Run `node --test --test-concurrency=1 tests/*.test.mjs` in this directory.
`AGENT_BRIDGE_TEST_CHROME` can name an explicit isolated test executable; candidate
qualification must use the packaged dedicated Chromium. Tests create fresh
private profiles and local synthetic HTTP fixtures and do not inspect user tabs.
Run Python archive tests with `python -m unittest discover -s scripts/rust
-p test_package_browser_worker.py`. The Rust provider tests additionally exercise
the actual MCP gateway, live profile guards and owned Job cleanup.
